# Release checklist

- [ ] Normal and slow tests pass
- [ ] Compileall, localization, content validation and benchmarks pass
- [ ] Asset and third-party license audits reviewed
- [ ] Project license selected by owner
- [ ] Version and changelog approved
- [ ] One-folder build and `verify_release.py` pass
- [ ] User paths and old-save migration verified
- [ ] Crash report reviewed for sensitive data
- [ ] Every item in `MANUAL_TEST_CHECKLIST.md` physically tested
- [ ] GitHub Actions pass after push
- [ ] Original release icon supplied or no custom icon accepted
- [ ] Owner creates final tag, release notes and GitHub Release
